M Maps_

Set a USB-connected phone's simulated GPS location from your computer, for development and device testing. The full pack is Mac (Apple silicon and Intel), Windows, Linux, and the Android Companion.

Free and open source. The Mac app is signed with an Apple Developer ID and notarized by Apple.

What M Maps does_

One local app moves the phone's simulated location and holds it until you restore real GPS.

  • Teleport

    Pick a point on the map, confirm it, and the phone holds that location.

  • Routes

    Walk, bicycle, motorcycle, or drive along real roads at realistic speeds.

  • Flights

    Great-circle flights that land at the nearest passenger airport.

  • Multi-stop trips

    Ordered stops with optional waits, all on the same connection.

  • Restore GPS

    One click stops the simulation and hands the phone back to real GPS.

How to check a download

Compare the SHA-256 shown for the file with the output of:

  • Mac: shasum -a 256 ~/Downloads/M-Maps-arm64.dmg
  • Windows PowerShell: Get-FileHash .\M-Maps-windows-x86_64.zip -Algorithm SHA256
  • Linux: sha256sum M-Maps-linux-x86_64.tar.gz

Install in three steps_

When the download finishes, follow the steps for the computer or phone you downloaded it to. Then connect the phone with a USB cable; Requirements lists what the phone needs.

macOS

Your next step

Mac

  1. Open the downloaded .dmg file from your Downloads folder.
  2. Drag M Maps onto the Applications folder in the window that opens.
  3. Open M Maps from Applications. If macOS asks about an app downloaded from the internet, choose Open. M Maps asks for your administrator password each time it starts.

For an Android phone, also install adb on the Mac, for example with brew install android-platform-tools.

Windows · Beta

Your next step

Windows

  1. In your Downloads folder, right-click M-Maps-windows-x86_64.zip and choose Extract All. If the browser warns about the download, choose Keep.
  2. Open the extracted MMaps folder and double-click run_m_maps.bat. If Windows says “Windows protected your PC”, choose More info, then Run anyway: the Beta build is not code-signed yet.
  3. M Maps opens in your web browser; if it does not, go to http://127.0.0.1:8765. Keep the black M Maps window open while you use it, and do not click inside it.

For an iPhone, first install Apple Devices from the Microsoft Store. For an Android phone, install Android platform-tools and add its folder to Path. If the phone does not show up, install its maker’s USB driver: the Samsung Android USB Driver for a Samsung phone, the Google USB Driver for a Pixel.

Linux · Beta

Your next step

Linux

  1. Install the phone tools: usbmuxd for an iPhone, adb for an Android phone. On Debian or Ubuntu: sudo apt install usbmuxd adb and, for Android, sudo usermod -aG plugdev "$USER", then log out and back in. On Fedora: sudo dnf install usbmuxd android-tools
  2. In a terminal, extract and start it: tar -xzf ~/Downloads/M-Maps-linux-x86_64.tar.gz, then ./MMaps/run_m_maps.sh
  3. M Maps opens in your web browser; if it does not, go to http://127.0.0.1:8765. Keep the terminal open while you use it.

Needs a 64-bit x86 PC with a recent system: Ubuntu 24.04, Debian 13, Fedora 40 or newer.

Android phone

Your next step

M Maps Companion

  1. Show Developer options by tapping Build number seven times (Settings > About phone, or About phone > Software information on Samsung), then turn on USB debugging there. On a Samsung phone, also turn off Auto Blocker.
  2. Install the app. Downloaded on the phone: open M-Maps-android-companion.apk from its Downloads; if Android asks, allow that app to install apps, and if Play Protect warns, choose Install anyway. Downloaded on the computer: plug the phone in, tap Allow on the USB debugging prompt, then in the folder with the file run adb install M-Maps-android-companion.apk
  3. Open M Maps Companion and allow location access. Then, in Developer options, choose M Maps Companion as the Mock location app.

Needs Android 8 or later and M Maps running on a computer. Keep the phone plugged in and tap Allow if it asks to allow USB debugging.

Requirements_

M Maps controls one phone at a time over a USB cable.

Mac app

  • macOS 12 Monterey or later.
  • Apple silicon or Intel. Apple silicon is tested; Intel hardware testing is in progress.
  • Open the DMG and drag M Maps to Applications.
  • Your administrator password each time M Maps starts.

iPhone

  • iOS 17 or later on a Mac (iOS 17.4 or later on Windows or Linux), connected by USB.
  • Unlocked, with Trust This Computer accepted.
  • Developer Mode on: Settings > Privacy & Security > Developer Mode.
  • On Windows, install the Apple Devices app from the Microsoft Store. On Linux, install usbmuxd. The Windows and Linux builds are Beta.
  • On Windows and Linux, M Maps asks once before it downloads the Developer Disk Image. Your phone’s identifiers go to Apple’s signing server for that download.

Android phone

  • USB debugging on, with this computer approved on the phone.
  • M Maps Companion installed and chosen under Developer options > Mock location app.
  • Android 8 or later.
  • Android platform-tools (adb) installed on the computer: brew install android-platform-tools on a Mac, sudo apt install adb on Debian or Ubuntu, or Google’s download with its folder added to Path on Windows.
  • Tested on a Samsung Galaxy A15 with Android 16. Other phones may behave differently.

Windows and Linux

  • A 64-bit x86 (x86_64) computer. On Linux, Ubuntu 24.04, Debian 13, Fedora 40 or newer.
  • Android phones and iPhones. iPhone needs iOS 17.4 or later, plus the Apple Devices app on Windows or usbmuxd on Linux.
  • Beta builds: launch-tested by the release workflow, with real-device testing still in progress.

Privacy and responsible use_

Privacy

M Maps has no telemetry and collects no user data. The phone connection stays between your computer and its USB cable.

This page has no analytics, cookies, or trackers. Your browser asks GitHub's public API for the latest release details, and the download buttons fetch files directly from GitHub.

Inside the app, maps, search, and routes come from separate services that are listed in the README.

Educational use only

M Maps is for educational device testing on phones you own or are allowed to test. Do not use it to deceive, defraud, or evade tracking.

A simulated location affects apps and services on the phone. You are responsible for following the law and the terms of the services you use.
